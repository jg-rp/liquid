Install
-------

Install ``python-liquid`` from PyPI_ using your favorite package manager.

**pip**

.. code-block:: shell

   python -m pip install python-liquid

**uv**

.. code-block:: shell

   uv add python-liquid   

**pipenv**

.. code-block:: shell

   pipenv install -u python-liquid
